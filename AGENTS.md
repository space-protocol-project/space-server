# Правила работы с кодом

- Общайтесь по-русски; сохраняйте понятные имена, небольшие функции и низкую когнитивную сложность.
- Используйте актуальный стабильный Go и свежие совместимые зависимости. Перед обновлением проверяйте выпуски, после него синхронизируйте генераторы и CI. Причины отложенного обновления описывайте явно; предварительные версии требуют прямого запроса.
- После изменений выполняйте `go test ./...`, `go vet ./...`, `go mod verify` и проверку вызываемого кода через `govulncheck`. Для конкурентного кода используйте `go test -race ./...`.
- PostgreSQL и runtime проверяйте на отдельной тестовой базе. Миграции, перезапуск, сохранность идентичности и резервное копирование должны сохранять свои проверки.
- При обновлении Connect синхронизируйте `go.mod` и `buf.connect.gen.yaml`, затем выполняйте указанную в README кодогенерацию.
