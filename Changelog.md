# Изменения сервера Space

## Unreleased

- Иконка сервера в настройках, публичном manifest и WatchChannels; миграция 011, роли owner/admin и проверка revision. Шесть preset, безопасный SVG и PNG до 8 КиБ. Обновление настроек старым клиентом без поля icon сохраняет существующую иконку.

- Экспериментальные маршруты ConnectRPC за флагом `-connect-rpc`: manifest, challenge-вход и подписка событий через существующий gRPC-сервер. Сохраняются его авторизация, ACL, отзыв и лимиты потоков. Connect-Go 1.19.2 совместим с Go 1.24; protobuf runtime поднят до требуемой версии 1.36.9.

- Серверное время сообщения `created_at_unix_ms` сохраняется при повторе и одинаково в ответе создания, истории и событиях. Миграция 010 оставляет старым сообщениям неизвестное время (0).

## v0.1.0 — 10 октября 2026 года

- Комплект Go-сервера с собственной PostgreSQL 17.11 для Windows x64, macOS arm64 и Linux x64.
- Постоянная база, server ID, ключи и сертификат сохраняются между включениями.
- Самоподписанный TLS-сертификат с IPv4 в SAN; HTTPS и HTTP/2 gRPC через один порт 8443.
- По умолчанию новое домашнее пространство принимает участников только по приглашениям; выбранная владельцем политика сохраняется при перезапуске.
- Первоначальное назначение владельца через локальный канал; внешний вход закрыт до завершения настройки.
- Штатная остановка сервера и PostgreSQL при закрытии управляющего канала приложения.
- Проверки перезапуска базы, локального владельца, TLS-приглашения, сообщения и сохранения идентичности.

Комплекты устанавливаются основным приложением Space после проверки закреплённой SHA-256. Не заменяйте работающий кластер другой основной версией PostgreSQL вручную. Домен и системная PostgreSQL не требуются; роутер и брандмауэр настраиваются владельцем. Публичный доступ через конкретное интернет-подключение ещё требует ручной проверки.
