# Сервер

Место первой серверной реализации. Код ещё не создан. После выбора основы сервер должен предоставлять discovery, manifest, identity/auth, каналы, ACL, actions, durable events и встроенную панель `/admin`.

Первый результат: воспроизводимый текстовый сервер с одним chat view. Медиа подключается отдельным адаптером. База, assets и server identity требуют долговечного хранения и проверенного backup.
