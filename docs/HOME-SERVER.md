# Домашний сервер

Пользовательское руководство находится в [space-app](https://github.com/space-protocol-project/space-app/blob/main/docs/HOME-SERVER.md).

Домашний runtime — тот же сервер с собственной PostgreSQL. Архитектурное решение: [ADR-028](https://github.com/space-protocol-project/space-protocol/blob/main/docs/adr/028-home-server-runtime.md).

Текущий runtime — [v0.2.2](https://github.com/space-protocol-project/space-server/releases/latest), закреплён в приложении v0.2.2. [Инструкция восстановления](https://github.com/space-protocol-project/space-app/blob/main/docs/HOME-RECOVERY.md), [актуальные снимки интерфейса](https://github.com/space-protocol-project/space-app/blob/main/docs/SCREENSHOTS.md).
