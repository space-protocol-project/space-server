Войти через существующее устройство

Создаётся новый рабочий ключ. Подтвердите запрос в Flutter или исходном браузере и сравните код проверки до выдачи подписи. Запрос для панели включает space.manage; сервер дополнительно проверяет вашу роль.

Передайте код на исходное устройство. Действует пять минут.

Восстановить прежнюю идентичность

Открывается только на этом устройстве. Будет создан новый рабочий ключ под прежней идентичностью. Карточка должна относиться к этому адресу и серверному ключу.

При первом входе создаётся отдельная идентичность в этом браузере. Она отличается от идентичности Flutter-клиента. Ключи сохраняются в IndexedDB. После входа сохраните зашифрованную карточку и проверьте восстановление прежде, чем удалять профиль браузера.

Первый запуск сервера

Через локальную консоль или SSH выполните:

space-server -setup-code

Команда использует SPACE_DATABASE_URL и выдаёт код на 15 минут. Сам сервер не нуждается в браузере.

Разрешение устройства истекло или отозвано?

Можно явно выдать новое разрешение через сохранённый корневой ключ. Это не восстановление потерянной идентичности; старые разрешения не отзываются этим действием.

Назначить первого владельца

Нужен одноразовый код из локальной команды сервера. При ручном режиме владелец назначается по коду. При автоматическом — первым успешным входом.

Настройки пространства

Выключение всех чатов закрывает чтение, отправку и подписку. Сообщения остаются в базе.

Закрытие регистрации не отзывает доступ существующих участников. По приглашению можно вступить и при закрытой регистрации.

Каналы

Чаты пространства. Архив сохраняет историю и запрещает новые сообщения. Права проверяет сервер.

Создать чат-канал

Участники смогут читать и писать, читатели — читать. Публичный предпросмотр выключен.

Предпросмотр раскрывает название и адрес, но не сообщения. Для полностью скрытой группы выключите его.

Права канала

Индивидуальное правило полностью заменяет правило роли. Удаление правила роли закрывает доступ этой роли. Владелец и администраторы сохраняют доступ. «Управлять» разрешает менять название, порядок и архив; менять права могут только администраторы пространства. Читатель не получает отправку, а устройству для управления нужно отдельное разрешение.

Участники и права

Читатель читает чат. Участник также пишет. Администратор меняет настройки и создаёт приглашения. Только владелец назначает роли и блокирует участников. Для управления устройству отдельно нужен space.manage.

Приглашения

Сохраните ссылку сейчас: сервер не сможет показать секрет повторно. Любой получивший ссылку может вступить с указанной ролью.

Сессия управления

Каждое действие проверяет права владельца, разрешение устройства и актуальность сессии на сервере.

Вы в пространстве

Для чата подключите Flutter-клиент по адресу сервера и коду приглашения. Браузер и Flutter пока имеют разные идентичности: для каждого вступления нужен отдельный код или свободное использование приглашения.

Смена корневого ключа

Сохраняет ID, права и историю. Старые устройства и карточки закрываются. Начать смену можно исходным корневым ключом; после сбоя завершите сохранённую смену.

Подтвердить новое устройство

Введите одноразовый код с нового устройства. Сначала сверяются коды, затем root или recovery key выдаёт подпись. Для подписи нужна исходная root-идентичность либо открытая карточка JSON/PNG. Для recovery-карточки новое устройство проверяет цепочку подписей от исходного root.

Восстановление и устройства

Карточка содержит зашифрованный ключ восстановления для этого сервера. Она позволяет подключать новые устройства с вашей идентичностью. Сервер не получает пароль или приватный ключ. Ключ восстановления действует до 3650 дней; потеря файла и пароля не восстанавливается сервером. QR-карточку можно скачать в PNG и открыть из изображения.

Устройства вашей идентичности

Отзыв карточки закрывает также устройства, подключённые через неё. Создать новый recovery key можно исходным root после отзыва предыдущего. Восстановленная идентичность может повторно использовать сохранённую карточку.
