# Эталонные модули для криптографических тестов

Эти Node/WebCrypto-модули проверяют совместимость с Dart и Go: подписи, историю root, зашифрованные карточки, QR и сопряжение. Они не являются клиентом, не содержат интерфейс панели и не публикуются сервером. Основное приложение находится в client/.

vendor содержит закреплённые QR-алгоритмы; лицензии и контрольные суммы сохранены в vendor-licenses. pngjs используется только для чтения/записи тестовых PNG. DOM-функции прежней панели удалены.
